Demo walkthrough

Try MiniLang.

Test the main workflow, then inspect how the interface and API work together.

Five-minute walkthrough

  1. Run the example: output is 3, 6, 9, 12 and 70.
  2. Inspect Tokens and AST.
  3. Run print 2 + 3 * 4; to check operator precedence.
  4. Run print 1 / 0; to see a useful runtime error.

Run and test

Start the app with python run.py. Run its automated checks with python -m unittest discover -v.

Data and limits

This is a single-user learning demo with synthetic sample data. Authentication and production deployment are outside its current scope.

Programs execute with explicit limits and cannot access Python, files, or the network. Programs are not saved after a page reload.
